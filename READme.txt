1. Install Python

Download and install Python 3.11 or newer.

During installation, check:

Add Python to PATH

2. Download the program

Download:

VLFDataGraphPro_v0.9_Alpha_EN.py

and save it to a folder, for example:

C:\VLFDataGraphPro

3. Open Command Prompt

Open the program folder, click into the address bar, type:

cmd

and press Enter.

4. Install the required libraries

Run:

python -m pip install numpy pandas matplotlib openpyxl xlrd python-docx

5. Start the program

Run:

python VLFDataGraphPro_v0.9_Alpha_EN.py

The application window will open and the user can select CSV, TXT, XLS or XLSX data files.

Linux
sudo apt install python3 python3-pip python3-tk
pip3 install numpy pandas matplotlib openpyxl xlrd python-docx
python3 VLFDataGraphPro_v0.9_Alpha_EN.py
Supported files
CSV
TXT
XLS
XLSX
XLSM
