# VLFDataGraphPro
Professional visualization and analysis software for long-term VLF/LF recordings.
## Features

- Fast CSV/XLS loading
- Multiple recording sessions
- Multi-channel plotting
- Daily statistics
- 3σ anomaly detection
- USGS earthquake overlay
- NOAA GOES solar flare overlay
- DOCX report export
- PNG / PDF / SVG export

## Installation

```bash
pip install -r requirements.txt
python src/VLFDataGraphPro.py
